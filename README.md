## 📋 درباره پروژه
**فرا ایده** یک پلتفرم **فول استک (Full-Stack)** برای ارائه خدمات طراحی سایت، سئو و مشاوره دیجیتال مارکتینگ هستش. این پروژه با جدیدترین تکنولوژی‌های وب مدرن ساخته شده تا تجربه‌ای سریع، امن و کاربرپسند رو برای کارفرمایان فراهم کنه. هدف من ایجاد پلی بین کارفرمایان و تیم برنامه‌نویسی حرفه‌ای بوده.

## ✨ ویژگی‌های کلیدی پروژه

### 👤 برای کارفرمایان (کاربران عادی)
- **صفحه اصلی**: معرفی خدمات و تیم برنامه‌نویسی
- **نمایش نمونه‌کارها**: گالری پروژه‌های انجام شده
- **مشاهده نظرات مشتریان**: بازخورد واقعی کارفرمایان قبلی
- **ارتباط با تیم**: فرم تماس برای درخواست مشاوره
- **پروفایل کاربری**: مشاهده درخواست‌ها و پروژه‌های ثبت‌نامی

### 👨‍💻 برای مدیران (ادمین)
- **داشبورد مدیریت کامل**: مشاهده آمار و درخواست‌ها
- **مدیریت پروژه‌ها**: افزودن، ویرایش و حذف نمونه‌کارها
- **مدیریت نظرات**: تایید و پاسخ به نظرات کاربران
- **مدیریت کاربران**: مشاهده لیست کاربران و سطح دسترسی‌ها
- **مدیریت محتوا**: ویرایش متون و بخش‌های مختلف سایت

## 🔐 احراز هویت و امنیت
<div align="center">
  
[![NextAuth](https://img.shields.io/badge/NextAuth.js-v5-000000?style=for-the-badge&logo=next.js)](https://next-auth.js.org/)
[![Google Auth](https://img.shields.io/badge/Google-OAuth-4285F4?style=for-the-badge&logo=google)](https://developers.google.com/identity/protocols/oauth2)
[![Zod](https://img.shields.io/badge/Zod-Validation-3E67B1?style=for-the-badge&logo=zod)](https://zod.dev/)

</div>

- **احراز هویت چندگانه**: سیستم احراز هویت امن با [NextAuth.js](https://next-auth.js.org/) v5
- **ورود با گوگل**: امکان ثبت‌نام و ورود سریع با حساب گوگل (Google OAuth)
- **اعتبارسنجی فرم‌ها**: تمام فرم‌ها با [Zod](https://zod.dev/) اعتبارسنجی می‌شوند تا امنیت و تجربه کاربری بهبود یابد
- **محافظت از مسیرها**: صفحات ادمین و پنل مدیریت فقط با دسترسی مناسب قابل مشاهده هستند
